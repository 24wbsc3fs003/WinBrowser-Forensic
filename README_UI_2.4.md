# WinBrowser Forensics v2.3.0 UI Enhancement

The left navigation rail has been redesigned as a professional forensic-workbench navigation system.

Highlights:
- Structured sections with clearer visual hierarchy.
- Scrollable navigation for smaller displays.
- Active-page highlight with teal forensic accent and left marker.
- Current-case context card showing the selected case and investigator.
- Navigation search field for quickly finding modules.
- Hover/focus states and tooltips on navigation controls.
- Persistent user/session footer and lock action.
- Existing case-scoped workflow remains unchanged; no case is automatically opened.
